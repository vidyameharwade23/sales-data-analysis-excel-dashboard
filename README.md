# Sales Data Analysis & Interactive Dashboard

## Project Overview

This project analyzes sales data using Microsoft Excel to identify sales trends, regional performance, product performance, and customer purchasing patterns.

The project includes data cleaning, validation, analysis, PivotTables, PivotCharts, interactive slicers, lookup functions, and KPI-based dashboard reporting.

## Tools & Technologies

- Microsoft Excel
- PivotTables & PivotCharts
- XLOOKUP & VLOOKUP
- SUMIFS & IF
- Filters & Conditional Formatting
- Interactive Slicers
- Data Cleaning & Validation

## Key Analysis

- Monthly revenue trends
- Regional sales performance
- Product-wise revenue analysis
- Top-performing products
- Customer purchasing patterns
- Average Order Value
- Sales opportunities

## Dashboard Features

- Total Revenue KPI
- Total Orders KPI
- Total Quantity Sold KPI
- Average Order Value KPI
- Monthly Revenue Trend
- Regional Revenue Performance
- Product Revenue Performance
- Region and Product slicers
- Order lookup using XLOOKUP and VLOOKUP

## Key Insights

- Laptop is the highest-revenue product.
- North is the highest-revenue region.
- Mouse has the lowest revenue among the products analyzed.
- Customer-level analysis helps identify high-value customers and purchasing patterns.

## Project File

The Excel workbook contains the raw data, cleaned data, analysis, PivotTables, and interactive dashboard.
